# Product Overview

## Purpose

This documentation demo shows how product and developer documentation can be authored, reviewed, and maintained as code.

## Audience

- Product users who need to understand the product
- Developers integrating with or extending it
- Contributors maintaining the documentation

## Documentation principles

- Write for the reader and their task.
- Prefer plain language and explain unfamiliar terms.
- Keep each page focused on one topic.
- Use headings, lists, and examples to make information easy to scan.
- Review documentation changes alongside product changes.
