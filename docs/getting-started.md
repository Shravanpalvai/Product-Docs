# Getting Started

Welcome to the Product Docs demo. Use this guide to explore the documentation and understand the example workflow.

## Find your topic

- Start with the [product overview](overview.md).
- Follow the [installation guide](../guides/installation.md) for an example task-based guide.
- Browse the repository README for the project purpose and suggested structure.

## Documentation contribution workflow

1. Find the page that needs an update, or create a new Markdown (`.md`) file in the appropriate directory.
2. Write clear, task-focused content and check links and examples.
3. Review the change in GitHub and open a pull request when collaboration or approval is needed.
4. Merge the reviewed change into the default branch.

## Markdown example

```markdown
# Page title

Briefly explain what the reader will learn or do.

## Next step

Give the reader a clear action or link to a related page.
```
